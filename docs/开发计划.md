## 0. 一句话

在无限画布上装配一套云系统（机器 / 容器 / 服务 / 端口 / 型号），
先判「**能不能运行**」（12 条规则），再算「**故障会波及谁**」（容量感知的接口级传播），
最后给「**怎么救最划算**」（多动作恢复序列），全程确定性、可解释、可回看。

### 1.2 不做（明确排除，避免范围蔓延）

- ❌ 真实故障注入（不碰真实 K8s / 不杀进程 / 不改 iptables）——本系统是**沙盘推演**
- ❌ 真实健康探测与监控接入（P7 以后才考虑）
- ❌ 多租户登录鉴权（只预留 `owner_id` + `sys_user`）
- ❌ 脚本级自定义规则（只做只读表达式，不做代码执行）
- ❌ 三维 / 大屏动效（画布交互优先，视觉后置）

## 4. 阶段规划（每轮：我做 → 你验收 → 你点头 → 下一轮）

> 「轮」= 一次完整交付（30–60 分钟工作量）。每轮结束我都会给你：**改了什么 + 怎么验证 + 截图或接口原文**。

### 4.0 执行顺序：后端算法先行（老大定的基调）

**后端算法是大头，前端只做够用的壳。** 所以不按"先搭界面"走：

| 步 | 内容 | 依赖前端？ | 验收方式 |
| --- | --- | --- | --- |
| 1 | 数据模型 + 建表 + **校验引擎 R01–R12** | 否 | 单测 + Swagger 调接口 |
| 2 | **传播算法**（反向邻接 + 多源 BFS + 路径回溯） | 否 | 单测（多源 / 环 / 跨工程 / 空故障） |
| 3 | **恢复算法**（三策略 + 五维评分 + 冗余校验） | 否 | 单测（各策略适用/不适用边界） |
| 4 | **增强算法 E1–E4**（容量感知 / 割点 / 隔离切口 / 序列搜索） | 否 | 单测 + 数字例子 |
| 5 | 最小前端：画布拖拽 + 连线 + 结果渲染 | 是 | 浏览器截图 |
| 6 | 历史、AI、打磨、容器化 | 是 | 演示跑通 |

前端功能优先级：
- **必做**：画布拖节点、连端口、属性面板、校验问题清单 + 红环、推演结果高亮。
- **后置**：小地图、框选、路径动画、大屏、主题美化（后端全绿之后再说）。


### P0 骨架（1 轮）

| 项 | 内容 |
| --- | --- |
| 目标 | 前后端能起、能连、能建库，空画布能打开 |
| 后端 | `pom.xml`、启动类、`Result`/异常/traceId、健康检查（含 DB 连通）、`application.yml`（MySQL + H2）、`init.sql`（8 张装配期表 + 型号种子） |
| 前端 | Vite 工程、三栏布局、SVG 空画布（网格 + 平移 + 缩放 + 状态栏） |
| 脚本 | 启动后端 / 启动前端 / 初始化数据库 三个 `.bat`、`README.md` |
| 验收 | ① `mvn package` 通过 ② `/api/health` 返回 `database=up` ③ 浏览器打开画布能拖动缩放 ④ 刷新视角不丢 |

### P1 装配与校验（3 轮）

**P1-a 数据层（1 轮）**
- 实体：`Project` / `DeviceModel` / `AssemblyNode` / `NodePort` / `AssemblyEdge` / `CheckRun` / `CheckItem` / `SysUser`
- 接口：工程 CRUD、型号库查询与新增、节点 CRUD（含端口一次性提交）、连线 CRUD、坐标批量保存、视角保存
- 验收：Swagger 里能建工程 → 加 3 个节点 → 连 2 条边 → 查询原样返回

**P1-b 画布（1 轮）**
- 拖节点入画布、拖动节点、连线（选边类型 + 选源/目标端口）、右侧属性面板（改名/型号/资源/端口/删除）
- 多工程切换、示例数据一键导入（电商 9 节点 12 边）
- 验收：鼠标拖出 9 节点 12 边，刷新后全部还在；同一端口能连多条

**P1-c 校验（1 轮）**
- `ValidateContext` + 12 条规则 + 评分 + 落库 + `/validate` 与 `/validations/latest`
- 画布红/黄环、问题面板（双击定位）、状态栏计数、800ms 防抖自动校验
- 验收：初始 9 节点判「可运行 90 分」；加一个 2C 容器 → 判「不可运行」，提示 host-a CPU 超配 5.0/4.0；删掉 → 恢复通过

### P2 故障与传播（2 轮）

- 第一轮：`fault_event` 表与接口、故障注入界面、节点状态标记
- 第二轮：`PropagationService`（反向邻接 + 多源 BFS + parent 回溯）、`propagation_analysis` 及三张子表、画布红橙黄高亮与路径动画
- 验收：注入 MySQL 主宕机 → 订单/用户服务判直接受影响、网关判间接；路径「mysql → order-svc → gateway」可查；故障恢复后历史仍在

### P3 恢复决策（2 轮）

- 第一轮：冗余组 CRUD（主备 / 双活）、备用节点校验
- 第二轮：`RecoveryService` 三策略评估 + 五维评分 + 推荐 + 策略对比页（三张卡 + 评分明细 + 推荐理由）
- 验收：注入 MySQL 主故障 → `failover` 适用且推荐，显示选中备用节点与优先级；无冗余组时 `failover` 不适用并说明原因

### P4 增强与自定义规则（2 轮）

- 第一轮：E1 容量感知传播（资源余量 → 传播强度）、E2 割点、E3 最小隔离切口
- 第二轮：E4 多动作恢复序列搜索（深度 ≤3）、自定义表达式规则（表单 + 试跑 + 开关，不参与评分）、规则管理页
- 验收：同一故障下报告多出「必崩 / 可能抖」分层、"关键单点"列表、隔离建议、恢复序列推荐（含次优路径对比）

### P5 历史与 AI（2 轮）

- 第一轮：历史分页 + 详情回看（故障源快照）+ 报告导出（Markdown / PDF 二选一）
- 第二轮：FastAPI AI 服务（诊断 + 问答），Java 转发，无 Key 自动降级规则版，`source` 字段标明来源
- 验收：能翻历史、能看当时快照；配 Key 后 AI 给出诊断，无 Key 时返回规则结论不报错

### P6 打磨与交付（2 轮）

- 第一轮：单测（校验规则逐条、BFS 多源/环路、评分边界）、H2 冒烟测试、日志文件滚动、画布调试浮层
- 第二轮：演示数据、`演示脚本.md`（答辩 8 分钟流程）、Dockerfile + compose、README 完善、源码打包
- 验收：一条命令启动、按脚本走完演示不卡壳、测试全绿

## 10. 算法专项（大头，单独立项验收）

### 10.1 校验引擎

| 编号 | 算法 | 必须覆盖的测试用例 |
| --- | --- | --- |
| R01/R03 | 端口占用与映射冲突 | 同主机同端口两节点 / 不同主机同端口（应通过）/ 映射端口撞车 |
| R02 | 端口越界 | 0、65536、负数 |
| R04–R06 | CPU/内存/磁盘超配 | 刚好等于（应通过）/ 超出 0.1 / 超出 2 倍 |
| R07 | 依赖缺失 | 指向已删除节点 / 服务无任何 middleware |
| R08 | 网络不可达 | 跨主机无 network_link / 有 network_link |
| R09 | 循环依赖 | 二元环 / 三元环 / 自环（应被前置拦截） |
| R10 | 入口不可达 | 网关断链 / 无网关 / 全通 |
| R11/R12 | 孤儿、主备不完整 | 0 条边 / 缺备 / 类型不相容 |

**性能目标**：500 节点、1000 条边，单次校验 < 100ms。

### 10.2 传播算法

| 用例 | 断言 |
| --- | --- |
| 单源线性链 A→B→C | A 为 direct，B 为 indirect，C 距离 2 |
| 双源同时故障 | 每个节点取最短距离，来源按故障 ID 打破平局 |
| 环 A→B→A | 不死循环，节点不重复 |
| 故障源自身 | 不计入受影响集 |
| 有接口级连边 | 路径里带上 8081→3306 的端口信息 |
| 空故障 | 返回空结果，不报错 |
| 跨工程数据 | 不串工程 |

**确定性**：同一输入连跑 100 次结果完全一致（单测里断言对象相等）。

### 10.3 恢复算法

| 用例 | 断言 |
| --- | --- |
| 仅 node_down | restart 适用且可推荐 |
| 有合格冗余组 | failover 适用、选中 priority 最小的备用 |
| 备用自身故障 | failover 不适用 + 原因含"备用节点存在激活故障" |
| 隔离会断入口 | isolate 不适用 + 风险 high |
| 三策略都适用 | 取最高分，同分按 restart→failover→isolate |
| 权重和 | 恒等于 1.00（代码里断言） |

### 10.4 增强算法

| 编号 | 算法 | 断言 |
| --- | --- | --- |
| E1 | 容量感知传播 | 余量 <10% 的节点传播强度打折；余量 >70% 正常 |
| E2 | 割点 | 星型拓扑中心被判为割点，叶子不是 |
| E3 | 隔离切口 | 返回近似最小点集，且切口后影响层数 ≤ 阈值 |
| E4 | 恢复序列 | 深度 3 内找到全恢复动作序列，无解时返回"不可恢复" |
